B) public_html/.htaccess — POORA FILE (yahi lagao; sirf-Angular wala MAT rakho)
================================================================================

Galati: sirf ye rules the (bina /api/ wale) — tab /api/* bhi index.html par jata tha:
  RewriteCond !-f / !-d  →  RewriteRule . /index.html

Hostinger File Manager → public_html → .htaccess → POORA replace neeche wale se:

--------------------------------------------------------------------------------
# Hostinger: /api → PHP, baaki → Angular SPA
<IfModule mod_negotiation.c>
  Options -MultiViews
</IfModule>

<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /

  RewriteCond %{REQUEST_URI} ^/api/ [NC]
  RewriteRule ^api(?:/(.*))?$ /api/public/index.php [L,QSA]

  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>
--------------------------------------------------------------------------------

Same file PC par:  qrcode-app-php\deploy\public_html_ROOT.htaccess
                  ya qrcode-app-ui\public\.htaccess  (npm run build ke baad browser\ mein bhi aata hai)

J2) Exotel — owner call masking (scan page)
================================================================================

Scan page: user enters THEIR mobile → server calls Exotel Connect API (From = scanner,
To = owner, CallerId = your ExoPhone). Exotel rings the scanner first; on answer,
connects to the vehicle owner.

.NET (appsettings / env): CallMeNow:Exotel — AccountSid, ApiKey, ApiToken, Subdomain
  (api.exotel.com or api.in.exotel.com), CallerId (ExoPhone digits), CallType (trans),
  DefaultIsd (91).

PHP (config.local.php or hPanel env):
  EXOTEL_ACCOUNT_SID, EXOTEL_API_KEY, EXOTEL_API_TOKEN, EXOTEL_SUBDOMAIN,
  EXOTEL_CALLER_ID, optional EXOTEL_CALL_TYPE, EXOTEL_DEFAULT_ISD.
  Optional EXOTEL_RING_OWNER_FIRST = 1 / true / yes / owner — pehle owner (agent) ring,
  phir scanner (customer); default 0 = pehle scanner, phir owner.
  Optional EXOTEL_SCAN_DIRECT_TEL = 1 — scan par sirf tel: IVR line + keypad code; web par number form band
  (IVR DID + ensure_qr_stickers_ivr_access_code.sql + /api/exotel/ivr/gather|connect zaroori).

API: POST /api/qr/{publicId}/exotel/connect-owner  JSON {"fromPhone":"..."}

Never commit API tokens — rotate if leaked.

Exotel IVR (optional — keypad se owner connect):
  MySQL ek baar: database/ensure_qr_stickers_ivr_access_code.sql
  PHP: EXOTEL_IVR_DID = ExoPhone DID jo caller dial kare (digits); optional EXOTEL_IVR_WEBHOOK_SECRET
       agar set ho to Exotel flow URLs mein ?secret=WHI_VALUE lagao.
  Endpoints (GET, JSON): /api/exotel/ivr/gather  → Gather applet Primary URL
                         /api/exotel/ivr/connect → Connect applet dynamic URL
  Exotel App Builder (recommended order): Incoming → Greeting (welcome audio/text) → Gather (URL = gather) → Connect (URL = connect).
  Pehle “welcome” Greeting applet se aayega; Gather API sirf code + instructions bolati hai. Optional env:
  EXOTEL_IVR_GATHER_PROMPT / EXOTEL_IVR_GATHER_REPEAT_PROMPT (poora welcome+steps ek string mein bhi de sakte ho).
  Scan API se milta hai ivrAccessCode + exotelIvrDialUri (jab EXOTEL_IVR_DID set ho).
